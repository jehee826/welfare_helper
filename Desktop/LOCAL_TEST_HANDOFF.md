# 확장 화면 상담 인계

현재 시연은 **Extension/의 unpacked MV3 Chrome 확장**이다. Electron·Windows UIA는 새 시연에서 실행하지 않는다. 확정 범위는 로컬 설계 `docs/design/extension-screen-assistant-plan.md`의 A→B→C이며 EC2의 D/E는 추후 요청 때 진행한다.

## 한일

- A의 실제 표시·지우기·본문 스크롤·팝업/화면 변경 후 해제는 사용자 확인으로 완료됐다. 같은 검사를 다시 요청하지 않는다.
- 실제 복지로 패널의 검색 질문에서 답변과 파란 강조가 검색 요소에 일치하는 것도 사용자 확인됐다. 확장 연결 파일을 불러온 상태이며 백엔드·Ollama·문서 워커는 정상 실행 중이다.
- B: 현재 공개 DOM의 제목·짧은 문맥·입력란 라벨·후보 ID와 질문을 기존 `/api/v1/desktop/guide`에 전달한다. 응답은 설명과 대상 0~3개이며, ID·화면 버전·가시성·모달·이름을 재검증한 후 색상·번호·이름을 함께 표시한다. 설명/추가질문에 대상을 강제하지 않는다.
- 서버는 제한된 `source=dom` 계약을 추가하고 이전 UIA 단일 대상 호출은 호환 유지했다. 공개 문구는 DOM 범위·길이·개수·민감정보 제한으로 검증하며 UIA 고정 이름 목록에 추가하는 방식으로 구현하지 않았다.
- 긴 요청은 확장 내부 offscreen 문서에서 수행한다. 서비스 워커는 설정·탭 권한·캡처만 짧게 처리한다. 한 번에 한 요청, 전체 90초, 취소/탭 이탈/연결 실패 시 표시 해제, 자동 재전송 없음이다.
- DOM 상담은 32자 이상의 연결 토큰을 요구한다. 확장은 고정된 localhost:8000만 사용하며 토큰은 extension storage.session에만 둔다. 페이지가 URL·JS·CSS·좌표 실행을 지정할 수 없다. 공개 Caddy의 Desktop 경로는 차단한다.
- C: activeTab을 실제 확장 아이콘 클릭으로 허용한 뒤 선택된 복지로 탭만 `captureVisibleTab`으로 수집한다. 패널과 강조를 제외하고 입력·선택 영역은 캡처 전에 검은 영역으로 덮으며 이미지 처리 때도 마스킹한다. 수집 전후 탭·URL·DOM 변경·스크롤·뷰포트 일치를 확인한다. 불투명 iframe/닫힌 커스텀 Shadow DOM/캔버스 등은 보류한다.
- 이미지는 PNG 한 장, 최대 1280×800, 원본 1.5MiB/base64 2MiB다. 이미지 미지원 모델/옵션 꺼짐/권한·수집 실패를 구분하고 이미지 없는 성공으로 바꾸지 않는다. 저장·로그·Git에 이미지/질문 원문을 남기지 않는다.
- 최소 실행 도우미 `Extension/start-local.ps1`을 준비했다. 기존 Qwen1.5B·bge-m3 캐시가 있어야 실행하며 .env를 열거나 수정하지 않는다. Docker가 정상일 때 기존 Compose의 백엔드와 의존 Ollama를 사용하고 연결 파일을 로컬에 준비한다.
- 집중 자동 검사: 확장 DOM/통신/캡처·중단 **20개**, 백엔드 DOM/이전 계약/공통 Ollama **55개**, 합계 **75개** 통과. JS 문법·manifest 파일 참조·PowerShell 실행 도우미 문법도 확인했다.
- 대표 공개 DOM 개발 데이터로 실제 Qwen1.5B API의 설명 응답(4.72초), 검색 대상(4.89초), 서로 다른 두 대상 설명(8.58초)을 확인했다. 이는 현재 Chrome의 실제 DOM 검증과 구분한다. 지시 대상이 없는 모호한 질문은 시선/포인터를 추측하지 않고 이름 확인을 요청하며 이 경우 모델을 호출하지 않는다.
- Terra가 실행 중인 loopback API에서 신규 오류 계약 4건을 통과시켰다. 토큰 없음 401, 인증 후 전달 헤더 403, 합성 PNG+이미지 off 409, 본문 크기 초과 413이다. 이 검사는 모델 호출·이미지 저장·서비스 변경 없이 수행했다.
- 실제 추론에서 확인한 대상 누락·내부 순번 유출을 보완했다. 명시적으로 여러 기능을 각각/비교해 묻고 현재 후보 이름이 2~3개 확인되면 그 수를 생성 계약에 반영한다. DOM 선택 키는 요소명이며 같은 이름은 실제 ID로 구분한다. 확장 번호·색상을 모델이 임의로 설명하면 응답을 거부한다.

## 할일

- 실제 Chrome에서 B의 설명 전용·모호한 항목·다중 대상과 C의 탭 캡처/PNG 호환성은 아직 미검증이다. 사용자 확인한 검색 연결 성공과 대표 DOM의 실제 모델 응답을 다른 화면·모든 질문의 정확도 보장으로 확대하지 않는다.
- Docker의 Inference manager 시작 오류는 사용자 재기동 후 정상화됐다. 기존 캐시 모델만 사용했고 새 모델을 다운로드하지 않았다. 서버 설정은 Qwen1.5B/문맥 16384/이미지 off/loopback/확장 토큰 주입 상태다. 문서 워커는 유지했다. **factory reset·데이터/런타임 경로 삭제는 하지 않았다.**
- 실제 모델 질문은 `이 화면에서 뭘 할 수 있어?`, `검색은 어디서 해?`, `이 항목은 무슨 뜻이야?`, 여러 공개 메뉴 설명 한 번만 최소 확인한다. 모호한 질문의 추가질문과 설명만 하는 답변도 정상이다. HTTP 200만으로 정확도 통과 처리하지 않는다.
- C의 실제 캡처는 공개 비민감 화면에서 **이미지 범위 검사 · 전송 없음**으로 먼저 확인한다. 탭 전환/스크롤 중 조합이 거부되는지 확인한다. 실제 VLM 추론은 EC2 기동 후까지 보류한다.
- Chrome 자동 조작 도구는 URL 판별 제한이 있고 브라우저 전용 연결 목록은 비어 있었다. 현재 도구 상태를 다시 확인하되 같은 A 검사·로드 승인을 반복하지 않는다. 사용자 확인과 도구의 실제 검증을 구분한다.

## 사용자 추가지침

- 현재 브랜치의 기존 미커밋 변경·사용자 Chrome·앱·서비스·데이터를 보존한다. 변경은 커밋·push·PR하지 않는다. 인계 문서는 추후 main 배포 PR에서 제외한다.
- 이후 자체 검증은 기존 Terra 하위 에이전트가 담당한다. 통과한 A/실제 검색 연결을 반복하지 않고 남은 신규 범위만 확인한다. 도구 보호장치를 우회하거나 성공하지 않은 실제 화면 검증을 통과로 기록하지 않는다.
- .env 직접 열람/편집, 키 출력, DB/스키마 변경·문서/임베딩 재적재, Vercel 변경, worktree는 하지 않는다.
- 지금 EC2 접속·조회·기동·전송·모델 다운로드·실제 VLM 추론을 하지 않는다. 사용자 기동+테스트 요청 뒤에만 D/E를 진행한다.
- 클릭·입력·스크롤·신청 제출은 제품이 대신 하지 않는다. 실제 확인은 개인정보 없는 공개 화면만 사용한다. UIA/DOM만으로 모든 민감정보의 부재를 보장하지 않는다.
- 앱·서버를 사용자가 테스트할 수 있도록 유지한다. 테스트용으로 시작한 요청/터널/측정 프로세스만 정리한다. 모델 캐시·데이터 볼륨은 삭제하지 않는다.

## 로컬 실행

1. Docker Desktop이 정상 실행 중이어야 한다. 저장소 루트의 Windows CMD에서 실행한다.

```cmd
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Extension\start-local.ps1
curl.exe -f http://127.0.0.1:8000/openapi.json -o NUL
```

도우미는 기존 모델 캐시만 사용하고 `OLLAMA_LLM=qwen2.5:1.5b-instruct`, `LLM_NUM_CTX=16384`, 화면 상담 on·이미지 off·loopback 바인딩을 프로세스 환경으로 전달한다. 새 모델은 다운로드하지 않는다. Docker 오류 시 연결 파일을 변경하지 않고 중지한다. 포트 충돌 시 다른 서비스를 강제로 종료하지 않는다.

2. 이미 설치한 확장은 `chrome://extensions`에서 새로고침하고 **복지로 탭도 새로고침**한다. 신규 PC는 개발자 모드 → 압축해제된 확장 로드 → `Extension` 폴더를 선택한다. 빌드/npm start는 필요 없다.
3. 패널의 **연결 설정**에서 `.local\extension-connection.json`을 불러온다. 이 파일은 런타임 비밀값이며 Git에서 제외된다. 내용을 채팅·로그에 복사하지 않는다. 브라우저 종료 후 storage.session이 지워지면 다시 불러온다.
4. 이미지 체크 없이 질문한다. 표시 색상과 번호는 확장이 ID에 맞춰 만든다. 서버 연결 오류·오래된 대상에는 이전 색상 지시가 현행 답변으로 남지 않아야 한다.
5. 로컬 이미지 계약 확인은 확장 아이콘을 눌러 activeTab 권한을 부여한 뒤 **개발용 표시 검사 → 이미지 범위 검사 · 전송 없음**으로 수행한다. 이 검사는 서버로 이미지를 보내거나 VLM을 호출하지 않는다. 개인정보가 보이는 화면에서는 실행하지 않는다.

## 집중 자동 검사

```cmd
node --test Extension\tests\*.test.cjs
.venv\Scripts\python.exe -m pytest BackEnd\tests\test_desktop_dom.py BackEnd\tests\test_desktop_guidance.py BackEnd\tests\test_ollama.py -q
```

DOM 검사는 기존 FrontEnd 개발 의존성 jsdom을 사용한다. 실제 Chrome·모델 정확도·최대 GPU 메모리 검증을 대체하지 않는다. 실행 전 기존 서비스와 검사용 프로세스를 구분한다.

## EC2 D/E, 사용자 기동 후에만

1. 현재 IP·접속·자원을 재확인한다. 마지막 알려진 값은 `ubuntu@15.164.190.21`, `/home/ubuntu/welfare_helper`, ignored 로컬 키 `welfare_helper__key.pem`이다. 실패 시 반복 접속하지 않는다.
2. 원격 브랜치·미커밋 변경·기존 Compose/모델·GPU/RAM을 확인하고 필요한 변경 파일만 복귀 가능하게 보존·전송한다. .env·키·캐시·개인 지침을 복사하지 않는다. 새 clone/worktree/상담 API/Compose를 만들지 않는다.
3. 공개 Caddy에서 `/api/v1/desktop/guide`의 404를 실제 확인하고 8000/11434는 외부에 공개하지 않는다. 기존 생성 모델·문맥 길이·옵션의 비밀 없는 실제 런타임 값을 복귀용으로 확보한다.
4. 비교 후보는 [qwen3-vl:4b](https://ollama.com/library/qwen3-vl:4b)이며 아직 채택하지 않았다. 공식 배포 크기 약 3.3GB는 전체 VRAM 사용량이 아니다. Ollama 0.12.7 이상·vision capability·실제 메모리 여유를 확인한다. 기존 생성 모델만 내리고 후보를 준비하며 bge-m3/1024·리랭커·DB를 유지한다. 두 생성 모델을 동시에 상주시키지 않는다.
5. 기존 Compose에 `OLLAMA_LLM`, `LLM_NUM_CTX=16384`, `DESKTOP_GUIDANCE_ENABLED=true`, `DESKTOP_IMAGE_ENABLED=true`, `DESKTOP_EXTENSION_TOKEN`, `BACKEND_BIND_HOST=127.0.0.1`을 비밀을 출력하지 않는 런타임 방식으로 주입한다. 토큰은 32자 이상 새 난수로 준비해 로컬 확장 연결 파일에만 안전하게 전달한다. .env를 열거나 수정하지 않는다.
6. Windows localhost:8000의 소유를 확인한 뒤 SSH 로컬 포워딩으로 같은 확장 API 주소를 유지한다. 기존 서비스를 임의 종료하지 않는다.

```cmd
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=15 -o ServerAliveCountMax=2 -L 127.0.0.1:8000:127.0.0.1:8000 -i welfare_helper__key.pem ubuntu@현재IP
```

7. 같은 공개 화면·질문·DOM 목록·이력으로 LLM 다음 VLM을 순차 비교한다. 모드 사이 대화·강조를 초기화하고 비교 전에는 클릭하지 않는다. 모델이 서로 다르면 전체 구성 비교이며 이미지 효과만 증명한 것으로 해석하지 않는다. 공통 모델 교체의 RAG 영향도 소수 근거 질문으로 확인한다.
8. 이미지 off/on, 실제 답변 근거·0~3개 ID·표시 일치·응답 시간·최대 GPU 메모리·실패를 비교한다. 비밀 없는 모델 태그/digest·설정·사례별 판정·시간/메모리만 로컬에 남긴다. 원본 이미지/base64/질문은 저장하지 않는다.
9. Spot 연결 단절 시 유한 시간 안에 종료하고 사용자 재요청을 기다린다. EBS·모델 캐시의 영구 보존을 보장하지 않는다. 별도 큐·유료 인프라·볼륨을 추가하지 않는다.
10. 사용자 채택 전에는 실제 기준 생성 모델/문맥/옵션으로 복귀하고 본인이 만든 터널·측정 프로세스만 종료한다. 기존 데이터와 모델 캐시는 유지한다.

## 이전 Desktop 경로

`Desktop/`의 Electron·UIA·투명 오버레이 변경은 보존돼 있다. 이전 실행은 Desktop에서 `npm ci` 후 `npm start`였지만 **현재 확장 시연에는 사용하지 않는다.** 이전 단일 대상 API는 호환 어댑터로 남기며, 새 실행 안내를 Desktop 중심으로 되돌리지 않는다.
