# 곁에 Chrome 확장

최신 업데이트: 2026-11-10 13:19 KST

공개 복지로 화면에서 복지 문서 상담과 DOM 화면 안내를 제공한다. 백엔드는 EC2의 **https://15.164.190.21**을 사용하며, 로컬 서버·SSH 터널·연결 파일은 사용하지 않는다.

## 설치와 사용

1. Chrome의 확장 관리에서 개발자 모드를 켜고 `Extension` 폴더를 압축해제 확장으로 로드한다.
2. 공개 복지로 페이지를 열면 상담 패널이 나타난다. 아이콘으로 패널을 닫거나 다시 열 수 있다.
3. **복지 상담**은 내 정보를 저장하거나 나중 입력을 선택한 뒤 질문한다. 관리자 로그인 없이 공개 게시 문서를 검색한다.
4. **화면 안내**는 현재 공개 화면의 요소를 설명하고 색상·번호 테두리로 표시한다. 클릭·입력·신청은 사용자가 직접 한다.

기존 설치를 갱신할 때는 같은 Chrome 프로필과 로드 폴더를 유지하고, 확장을 제거하지 말고 새로고침한 뒤 복지로 탭도 새로고침한다. 새 폴더를 별도 확장으로 설치하면 기존 저장소를 자동 공유하지 않는다.

## 화면과 상담 데이터

제목줄·선택 상태·전송 버튼은 복지로와 어울리는 파랑(#3e61d7)을 사용한다. 본문은 16px, 보조 안내는 13px 이상이며 기본 한국어 시스템 글꼴을 사용한다. **내 정보와 ⋯ 메뉴**는 브라우저의 사이트 콘텐츠 화면 전체를 덮는 배경 위에 하나씩 여는 모달이다. 네 모서리를 둥글게 표시하고 내부를 스크롤한다. ×·Esc·바깥 배경 클릭으로 닫으면 원래 포커스·대화·질문 초안·스크롤이 돌아오며, 열기/닫기만으로 미저장 입력을 저장·취소하거나 진행 요청을 중지하지 않는다. 모달이 열려 있는 동안 사이트와 상담 패널의 마우스·키보드·스크롤을 차단한다. 패널 닫기·접기·모드 변경은 모달 차단을 해제하며 기존 요청 취소 동작을 유지한다. OS·브라우저 제목줄의 전체 화면 기능은 사용하지 않는다.

내 정보의 저장·확장 관리에는 별도 **확장 옵션** 메뉴와 **음성 입력 안내** 토글을 두지 않는다. 관리자 웹은 **⋯ → 관리자 접근**에서 연다. 마이크를 누르면 기존 녹음 화면에서 외부 인식 서비스 전송 고지·최대30초 한국어 입력 안내·취소 버튼을 제공하며, 마이크 권한과 오류 안내도 유지한다.

왼쪽 **⤡** 손잡이는 현재 콘텐츠 화면의 각 변에 최소4px 여백만 남기는 크기까지 늘릴 수 있다. 기본400×720px·최소320×360px·방향키20px 간격은 유지하고, 기존640×900px 제품 상한은 제거했다. 저장 검증의 기술 상한은 각 변16384px이며 기존 저장 형식과 값도 그대로 읽는다. 작은 화면에서는 표시만 줄이고 창을 다시 넓히거나 F5를 하면 저장한 선호 크기·위치를 복원한다. 제목줄 더블클릭으로 오른쪽 기본 위치로 돌아가며 **내 정보 → 저장·확장 관리 → 화면 설정**에 기본값 복원이 있다.

불투명도는 **질문/안내 바로 왼쪽의 슬라이더 하나**로10~100%를1% 간격으로 조절한다. 입력 중 즉시 보이고 포인터 조절 종료 시 한 번, 키보드는 마지막 변경400ms 후 저장한다. **플로팅 UI 전체**에 적용하므로 제목줄·말풍선·글자·입력·버튼·정보 사용 토글도 함께 투명해진다. 패널과 분리된 내 정보/⋯ 모달 카드는 각각 한 번만 합성해 중복으로 옅어지지 않으며 원래 색·비활성 상태 표시를 유지한다. 사이트 자체·모달 배경막·DOM 안내 강조는 조절하지 않는다. 제목줄의 내 정보는60×44px, ⋯·−·×는44×44px 둥근 사각 버튼, 질문/안내는 각각 최소64px다. 좁은 패널에서는 슬라이더·모드 선택을 두 번째 줄에 나란히 놓고 낮은 패널에서는 본문 스크롤로 입력·전송까지 접근한다. 수집 고지·요약·조건 사용 선택을 색상만으로 구분하지 않는다.

- 화면 안내를 요청할 때 공개 요소 이름·주변 문구와 제한된 화면 모드 이력만 EC2로 보낸다. 이미지 캡처, 제목·URL·입력값·내 정보·문서 요약·관리자 토큰은 보내지 않는다. 로그인·인증·개인정보 화면에서는 사용하지 않는다.
- 복지 상담은 질문·제한한 최근 문답·직접 사용자 발화와 주제 참조를 EC2로 보낸다. 저장 프로필은 기본적으로 추천 질문에만 사용한다. **질문 입력란 바로 위의 저장한 내 정보 사용**을 켜고 현재 프로필 제공에 동의한 경우에만 나이·소득·가구·지역·장애 여부를 최종 답변 생성에 제공한다. 기본은 OFF이며 검색·검색 준비에는 사용하지 않는다. 끄면 화면 기록과 프로필은 남기고 자동 맥락을 새로 시작한다. 프로필을 변경하면 기존 제공 동의는 무효가 되어 다시 확인해야 한다. 호환용 옛 요약은 현재 검색·생성 근거로 사용하지 않는다. 화면과 이미지는 수집하지 않는다. 실명·주민번호·계좌번호·개인 연락처를 입력하지 않는다.
- 프로필과 공개 상담은 같은 브라우저의 확장 저장소에 보관한다. 최근 **30문답**을 유지하며 기기 간 동기화하지 않는다. 확장 제거·저장소 삭제 시 복구되지 않고, 공용 브라우저에서는 기록이 공유될 수 있다.
- 마지막 실제 질문 전송 후 **7일 이상** 지나면 이전 자동 맥락·요약·문서 참조·직접 조건을 함께 제외한다. 화면 기록은 보존하며, 패널 열기나 답변 저장 재시도는 이 시각을 연장하지 않는다. 전송 시각을 확인할 수 없는 이전 기록도 자동 맥락에서 제외한다.
- 내 정보에서 조건 수정과 기록 삭제를 제공한다. 저장 실패를 알리고 원본을 조용히 삭제하지 않는다. 문서 내용·상담 요약은 실행 명령으로 취급하지 않는다.

상담 저장 형식은 v1/v2에서 v3로 이관한다. 이관 저장 실패 시 원본을 유지하고 질문을 막는다. v3를 지원하지 않는 이전 확장으로 단순 복귀하거나 저장값을 v2로 강제 변환하면 새 기록을 읽지 못하거나 잃을 수 있으므로, 복구는 v3를 읽을 수 있는 수정 버전으로 진행한다. 별도 전체 백업 키를 자동 생성하지 않는다.

정보 사용 선택은 `gyeote.profileUsage`의 별도 revision으로 저장한다. OFF 전환은 이 선택과 상담 맥락 경계를 함께 저장하며, 실패하면 이전 선택을 표시한다. 서버 지원이 없거나 동의/현재 프로필을 확인하지 못하면 프로필을 보내지 않는다. 질문에서 다른 상담 대상이나 조건을 직접 정정한 내용이 본인 저장 조건보다 우선하며, 추천은 최종 수급 자격 판정이 아니다.

질문 모드의 사용 선택은 입력란 바로 위에 **ON/OFF 스위치로 항상 표시**한다. 로컬 정보와 사용 선택을 읽으면 서버 지원 응답을 기다리지 않고 표시하며, 등록 정보가 있으면 지원 확인 중에도 스위치를 조작할 수 있다. 실제 ON 저장은 동의·현재 프로필 revision과 서버 지원을 확인한 뒤 완료한다. 서버 미지원·정보 미등록·읽기 실패에서는 불가 사유를 표시한다. 관리자 상담은 저장 동의를 변경하지 않고 비활성 OFF로 안내하며 내 정보를 보내지 않는다. 화면 안내 모드에서는 이 선택을 표시하지 않는다. 기존 ON 선택의 서버 지원을 확인하지 못했을 때는 저장 정보를 보내지 않으며 사용 선택을 끌 수 있다. 정보가 있다는 이유만으로 OFF를 ON으로 바꾸지 않는다.

로컬에 저장된 내 정보가 없으면 서버 지원 확인을 기다리지 않고 등록 안내를 표시한다. 정보 없음·읽는 중·읽기 실패를 구분하며, 프로필/사용 설정 읽기 응답이5초 안에 오지 않으면 원본을 보존하고 실패를 안내한다. 사용 설정은 입력란 위의 **다시 확인**, 프로필은 내 정보의 **최신 정보 다시 불러오기**로 재조회한다. 확인 중이거나 확인에 실패한 요청에는 저장 프로필을 첨부하지 않으며 저장된 ON 동의를 자동으로 OFF로 바꾸지 않는다.

답변에는 본문과 기관·전화·운영시간을 표시한다. 별도로 덧붙이던 참고자료 패널·출처 링크·자료 대조일·저장 답변의 유효성 안내는 표시하지 않는다. 답변 본문과 문서 자체의 안내 문구는 보존하며, 내부 출처·문서 버전·근거 저장 계약은 유지한다.

연락처 기록 수집이 활성화된 서버에서는 공개 상담 최초 진입부터 입력창 위에 수집 항목·90일 보존/자동 삭제·관리자 기간별 삭제를 알린다. 질문 전송 직전에도 현재 활성 상태를 다시 확인하고, 확인에 실패하면 질문을 보내지 않는다. 비활성·기존 404 서버는 수집 중이라고 표시하지 않는다. 수집 대상은 기관·번호·출처·문서 버전의 익명 연락처 안내 기록이며 질문·답변·요약·프로필·IP를 이 기록에 저장하지 않는다. 실제 활성화는 [운영 준비 절차](../deploy/README.md#연락처-기록-활성화와-복구)를 따른다.

**상담 요약** 버튼은 상단의 **내 정보 바로 왼쪽에 항상 표시하고 클릭할 수 있다.** 누르면 요약 창에서 마지막 저장 요약을 보여 주며, 창을 여는 것만으로 생성 요청을 보내지 않는다. 창 안의 **요약하기**를 누르면 확장 로컬에 보관된 공개 대화를 기존 요약 API에 전달한다. 저장 대화가 있으면 화면 모드·다른 질문 진행·미저장 답변과 무관하게 요약을 요청한다. 내부 버튼은 공개 접근·중복 요약·저장 대화 유무만 확인하며 기존 저장 충돌 처리는 유지한다. 수동 요약은 RAG의 7일·주제·정보 OFF 자동 맥락 경계와 별개로 보관된 최근30문답을 사용한다. 최대60메시지/12000자이며 길면 최근 완전 문답만 선택해 일부 요약으로 표시한다. 검색이나 사실 재검증은 하지 않는다. worker가 최대1200자의 마지막 성공본 하나를 `chrome.storage.local`의 `gyeote.displaySummary`에 저장해 F5 후에도 요약 창에서 다시 볼 수 있다. 새 성공본이 이전 것을 교체하고, 창 닫기는 화면만 닫으며 전체 대화 삭제·저장소 재설정은 요약도 지운다. 이전 버전의 메모리 요약은 자동 복구하지 않는다. 취소·실패·늦은 응답은 저장 성공본을 덮지 않고, 기존 v3 대화와 RAG 자동 맥락·요약은 유지한다. 표시용 요약은 다음 검색·답변이나 DB에 보내지 않는다. 생성 중 질문 전송은 막고 초안은 보존하며, 취소가 서버 추론의 즉시 종료를 보장하지는 않는다.

## 관리자 연결

패널의 **관리자 접근**은 기존 관리자 웹을 연다. 문서 등록·교체에는 관리자 웹의 로그인이 필요하며 확장 세션과 자동 연동하지 않는다.

Chrome 확장 관리 화면에서 여는 곁에의 옵션에는 비공개 자료의 시험 질의에 사용하는 관리자 로그인·로그아웃만 둔다. 비밀번호는 저장하지 않고, 토큰은 해당 HTTPS origin에 묶인 세션 저장소에만 보관한다. 서버 주소 변경·만료·확장 새로고침·브라우저 종료 후에는 다시 로그인한다. **로그아웃 · 익명으로 전환**은 서버 세션 해제를 시도하며, 실패하면 확인되지 않았음을 표시한다.

## HTTPS 패키지 생성

서버 origin은 `protocol.js`의 정적 설정에 둔다. 페이지 메시지·저장소·파일로 바꾸지 않는다. 배포용 복사본은 저장소 루트 CMD에서 생성한다.

```cmd
node Extension/package.cjs --origin https://15.164.190.21 --name ec2-release --timeout 600
```

결과는 `.local/extension-packages/ec2-release`이며 운영 파일 **15개**만 포함한다. 원본과 기존 출력은 덮어쓰지 않는다. HTTPS origin 하나로 protocol·manifest 호스트 권한·options/offscreen CSP를 함께 생성한다. HTTP·localhost·loopback origin은 거절하며, 테스트에는 접속하지 않는 HTTPS 가짜 origin을 사용할 수 있다.

모든 패키지는 문서 상담과 DOM 안내를 제공한다. 별도 `--remote-screen` 패키징 옵션이나 연결 JSON은 필요하지 않다. 패널의 질문·안내 모드 선택은 유지한다. 공개 확장 요청에는 고정 인증토큰을 넣지 않으며, 호스트 권한·확장 ID·CORS를 사용자 인증으로 취급하지 않는다.

## 기한과 취소

문서 상담은 기본 **600초**, 화면 안내는 **90초와 패키지 기한 중 작은 값**이다. `--timeout`은 정수 **1~1800초**이며 서버 설정과 별개다. 서버의 `OLLAMA_TIMEOUT=900`만 바꿔도 패키지의 600초는 바뀌지 않는다.

준비부터 응답까지 같은 기한을 적용하고, 정지·모드 변경·화면 이탈 시 진행 요청과 늦은 응답을 정리한다. 자동 재전송하지 않는다. 취소가 GPU 추론의 즉시 중단을 보장하지는 않는다.

서버의 `REMOTE_DOM_GUIDANCE_ENABLED`가 꺼져 있으면 화면 API는 제공되지 않는다. EC2 내부 loopback·Docker·Ollama 및 별도 Desktop/VLM 설정은 확장 연결 방식과 분리하며, [서버 운영 안내](../deploy/README.md)를 따른다.
