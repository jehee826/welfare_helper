# 곁에 Chrome 확장

공개 복지로 화면에서 복지 문서 상담과 DOM 화면 안내를 제공한다. 백엔드는 EC2의 **https://15.164.190.21**을 사용하며, 로컬 서버·SSH 터널·연결 파일은 사용하지 않는다.

## 설치와 사용

1. Chrome의 확장 관리에서 개발자 모드를 켜고 `Extension` 폴더를 압축해제 확장으로 로드한다.
2. 공개 복지로 페이지를 열면 상담 패널이 나타난다. 아이콘으로 패널을 닫거나 다시 열 수 있다.
3. **복지 상담**은 내 정보를 저장하거나 나중 입력을 선택한 뒤 질문한다. 관리자 로그인 없이 공개 게시 문서를 검색한다.
4. **화면 안내**는 현재 공개 화면의 요소를 설명하고 색상·번호 테두리로 표시한다. 클릭·입력·신청은 사용자가 직접 한다.

기존 설치를 갱신할 때는 같은 Chrome 프로필과 로드 폴더를 유지하고, 확장을 제거하지 말고 새로고침한 뒤 복지로 탭도 새로고침한다. 새 폴더를 별도 확장으로 설치하면 기존 저장소를 자동 공유하지 않는다.

## 화면과 상담 데이터

- 화면 안내를 요청할 때 공개 요소 이름·주변 문구와 제한된 화면 모드 이력만 EC2로 보낸다. 이미지 캡처, 제목·URL·입력값·내 정보·문서 요약·관리자 토큰은 보내지 않는다. 로그인·인증·개인정보 화면에서는 사용하지 않는다.
- 복지 상담은 질문·제한한 최근 문답·직접 사용자 발화와 주제 참조를 EC2로 보낸다. 저장 프로필은 추천 질문에만 사용하며 전송하지 않는다. 호환용 옛 요약은 현재 검색·생성 근거로 사용하지 않는다. 화면과 이미지는 수집하지 않는다. 실명·주민번호·계좌번호·개인 연락처를 입력하지 않는다.
- 프로필과 공개 상담은 같은 브라우저의 확장 저장소에 보관한다. 최근 **30문답**을 유지하며 기기 간 동기화하지 않는다. 확장 제거·저장소 삭제 시 복구되지 않고, 공용 브라우저에서는 기록이 공유될 수 있다.
- 내 정보에서 조건 수정과 기록 삭제를 제공한다. 저장 실패를 알리고 원본을 조용히 삭제하지 않는다. 문서 내용·상담 요약은 실행 명령으로 취급하지 않는다.

## 관리자 연결

패널의 **관리자 접근**은 기존 관리자 웹을 연다. 문서 등록·교체에는 관리자 웹의 로그인이 필요하며 확장 세션과 자동 연동하지 않는다.

확장 옵션에는 비공개 자료의 시험 질의에 사용하는 관리자 로그인·로그아웃만 둔다. 비밀번호는 저장하지 않고, 토큰은 해당 HTTPS origin에 묶인 세션 저장소에만 보관한다. 서버 주소 변경·만료·확장 새로고침·브라우저 종료 후에는 다시 로그인한다. **로그아웃 · 익명으로 전환**은 서버 세션 해제를 시도하며, 실패하면 확인되지 않았음을 표시한다.

## HTTPS 패키지 생성

서버 origin은 `protocol.js`의 정적 설정에 둔다. 페이지 메시지·저장소·파일로 바꾸지 않는다. 배포용 복사본은 저장소 루트 CMD에서 생성한다.

```cmd
node Extension/package.cjs --origin https://15.164.190.21 --name ec2-release --timeout 600
```

결과는 `.local/extension-packages/ec2-release`이며 운영 파일 **15개**만 포함한다. 원본과 기존 출력은 덮어쓰지 않는다. HTTPS origin 하나로 protocol·manifest 호스트 권한·options/offscreen CSP를 함께 생성한다. HTTP·localhost·loopback origin은 거절하며, 테스트에는 접속하지 않는 HTTPS 가짜 origin을 사용할 수 있다.

모든 패키지는 문서 상담과 DOM 안내를 제공한다. 별도 `--remote-screen` 패키징 옵션이나 연결 JSON은 필요하지 않다. 패널의 질문·안내 모드 선택은 유지한다. 공개 확장 요청에는 고정 인증토큰을 넣지 않으며, 호스트 권한·확장 ID·CORS를 사용자 인증으로 취급하지 않는다.

## 기한과 취소

문서 상담은 기본 **600초**, 화면 안내는 **90초와 패키지 기한 중 작은 값**이다. `--timeout`은 정수 **1~1800초**이며 서버 설정과 별개다. 서버의 `OLLAMA_TIMEOUT=900`만 바꿔도 패키지의 600초는 바뀌지 않는다.

준비부터 응답까지 같은 기한을 적용하고, 정지·모드 변경·화면 이탈 시 진행 요청과 늦은 응답을 정리한다. 자동 재전송하지 않는다. 취소가 GPU 추론의 즉시 중단을 보장하지는 않는다.

서버의 `REMOTE_DOM_GUIDANCE_ENABLED`가 꺼져 있으면 화면 API는 제공되지 않는다. EC2 내부 loopback·Docker·Ollama 및 별도 Desktop/VLM 설정은 확장 연결 방식과 분리하며, [서버 운영 안내](../deploy/README.md)를 따른다.
