# 장애아보육료지원

- 분야: 보육 / 장애아 보육료 / 중앙부처(교육부 영유아재정과)
- 서비스 ID: WLF00001067
- 지원대상: 장애인복지카드(등록증)를 가진 미취학 12세 이하 장애아동. 예외적으로 특수교육대상자로 선정된 3~5세 아동이 진단·평가 결과 통지서를 제출한 경우, 질병 등으로 일반 초등학교·특수학교에 취학하지 못한 장애아동이 복지카드를 소지하거나 통지서를 제출한 경우, 복지카드·통지서가 없는 5세 이하 영유아가 장애 소견이 있는 의사진단서를 제출한 경우에도 지원할 수 있다. 장애아가 부득이하게 휴학한 경우에도 지원 가능하며, 복지카드 소지자는 6세 이상 12세까지, 통지서 제출자는 6세 이상 8세까지다.
- 선정조건: 보호자의 소득수준과 관계없이 지원하되 장애인복지카드(등록증), 장애 소견이 있는 의사 진단서, 특수교육대상자 진단·평가 결과 통지서 중 하나를 제출해야 한다. 의사 진단서는 장애인등록용 장애진단서와 다르며 장애등급을 적을 필요는 없지만, 장애 소견이 「장애인복지법 시행령」 별표1의 장애인 종류·기준에 해당해야 한다. 진단기관은 장애인복지사업안내의 장애진단기관(의료기관)·전문의 기준에 한정된다.
- 지원내용: 장애아반 편성아동 634,000원, 3~5세 누리반(장애아) 아동 634,000원을 지원한다. 일반아동반에 편성된 장애아동은 시·도지사가 고시한 연령별 보육료 수납한도액을 지원한다.
- 유의사항·예외: 장애아동이 정부지원을 받는 특수학교(유치부 또는 초등학교 과정)를 이용하면 장애아 무상보육료를 받을 수 없으며, 초등학교 과정 아동은 방과후 보육료 지원이 가능하다. 특수교육대상자는 8세까지 장애아방과후보육료를 받을 수 있다.
- 신청방법: 해당 읍면동 주민센터를 방문하거나 복지로에서 온라인으로 신청한다. 읍면동이 접수하고 시군구가 조사·결정·지원한다.
- 온라인 경로: 복지로 로그인 → 서비스 신청 → 복지서비스 신청 → 복지급여 신청 → 영유아 → 보육료(어린이집).
- 준비서류: 사회보장급여(사회서비스이용권) 신청(변경)서와 장애인복지카드(등록증), 장애 소견 의사 진단서, 특수교육대상자 진단·평가 결과 통지서 중 해당 서류.
