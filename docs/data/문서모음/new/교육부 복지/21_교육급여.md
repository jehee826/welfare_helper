# 교육급여(맞춤형 급여)

- 분야: 교육 / 기초생활보장 교육급여 / 중앙부처(교육부 학생지원총괄과)
- 서비스 ID: WLF00001089
- 지원대상: 초등학교·공민학교, 중학교·고등공민학교, 고등학교·고등기술학교, 특수학교, 이와 유사한 각종학교, 고등학교 졸업 이하 학력이 인정되는 학교형태의 평생교육시설에 입학 또는 재학하는 기초생활보장 수급자. 「의사상자 등 예우 및 지원에 관한 법률」 제12조에 따른 의사상자의 자녀도 지원대상으로 열거되어 있다.
- 선정조건: 소득인정액이 기준중위소득 50% 이하인 가구의 초·중·고등학생을 지원한다. 교육급여는 부양의무자 기준을 적용하지 않는다.
- 지원내용: 초·중·고등학생에게 교육활동지원비와 입학금·수업료·교과서비를 지원한다. 교육활동지원비는 연 1회 초등학생 502,000원, 중학생 699,000원, 고등학생 860,000원이다. 고등학생 교과서는 해당 학년 정규 교육과정 교과목의 교과서 전체(연 1회)이며, 입학금·수업료·교과서비는 수급학생 재학 학교에 실비로 지급한다.
- 유의사항·예외: 상세정보에 별도 제외 조건이 없다.
- 신청방법: 거주지 행정복지센터를 방문하거나 복지로 또는 교육비원클릭신청시스템에서 온라인으로 신청한다. 읍면동이 접수하고 시군구가 조사·심사하며, 학교가 대상자를 확정하고 한국장학재단이 지원한다. 사후관리는 시도교육청이 맡는다.
- 온라인 경로: 복지로 로그인 → 서비스 신청 → 복지서비스 신청 → 복지급여 신청 → 교육급여.
- 준비서류: 사회보장급여 신청(변경)서, 금융정보 등(금융·신용·보험정보) 제공 동의서. 참고자료로 2026년 국민기초생활보장사업 교육급여 운영방안 안내가 게시되어 있다.
- 문의: 한국장학재단 고객센터 1599-2000.
