# 방과후보육료지원

- 분야: 보육 / 취학아동 방과후 보육료 / 중앙부처(교육부 교육보육과정지원과)
- 서비스 ID: WLF00001140
- 지원대상: 차상위 이하(법정 저소득층 포함) 또는 장애아동에 해당하는 12세 이하 초등학교 취학아동이 방과후에 어린이집을 일일 4시간 이상 이용하는 경우.
- 선정조건: 차상위 이하 기준은 ① 기초생활보장급여(생계·주거·의료·교육·해산·장제·자활) 수급자(특례수급권자 포함) ② 한부모가족지원법에 따른 지원대상 한부모 가정 ③ 아동복지시설에서 생활 중인 아동 ④ 여성폭력피해자 보호시설(가정·성폭력)·성매매피해자 지원시설에 입소한 여성의 동반자녀 ⑤ 모·부자(일시)보호시설 등에 입소한 사람의 동반자녀 ⑥ 미혼모자 공동생활가정에 입소한 사람의 동반자녀 ⑦ 차상위계층의 자녀이다. ①~⑦ 어디에도 해당하지 않는 신규신청자는 사회복지서비스 및 급여신청서로 해당 급여와 영유아보육을 동시에 신청해 자격 확인 후 결정되며, 신청일 기준으로 보장이 결정된다.
- 지원내용: 일반아동은 월 10만원이다. 장애아동은 교사 대 아동 비율 1:3으로 반을 편성하고 방과후·장애아보육 보수교육 과정을 이수한 교사를 별도 배치하면 장애아보육료의 50%(317,000원)를 지원한다. 6개월 이내 보수교육 이수를 전제로 교사를 배치한 경우도 이수 교사를 배치한 것으로 본다. 이 조건을 충족하지 않으면 정부지원시설은 월 10만원, 정부미지원시설은 시·도지사가 정한 5세아 보육료 수납한도액의 50%를 지원한다. 방학 중 일 8시간 이상 이용하면 해당일을 추가 지원한다. 방학기간 종일제 보육의 지원단가는 월 20만원이고 장애아동은 장애아보육료 100%이며, 이용 일자에 따라 일할 계산한다(예: 10일 이용 시 지원단가×10/26).
- 유의사항·예외: 일일 4시간 미만 이용하면 지원하지 않는다. 이용시간은 아동이 어린이집에 도착한 시간부터 마치는 시간까지만 산정하며 어린이집 셔틀버스 이용시간은 포함하지 않는다.
- 신청방법: 읍면동 주민센터를 방문하거나 복지로에서 온라인으로 신청한다. 읍면동이 접수하고 시군구가 조사·결정·지원·사후관리를 맡는다.
- 준비서류: 상세정보에 구체 목록이 없다. 시설 입소 여성·미혼모자 공동생활가정 입소자의 동반자녀는 재소 증빙서가 필요하다. 참고자료로 2026년도 보육사업안내가 게시되어 있다.
