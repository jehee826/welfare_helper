# 복권기금 꿈사다리 장학사업

- 분야: 교육 / 저소득층 초중고 장학금 / 중앙부처(교육부 학생지원총괄과)
- 서비스 ID: WLF00003177
- 지원대상: 「초중등교육법」상 학교에 재학 중인 초5~고3 학생 중 역량과 잠재력이 있는 우수학생 등. 기본 요건은 학교 추천일 기준 국민기초생활수급자, 한부모가족 지원대상자, 법정 차상위계층 학생이다.
- 선정조건: 2026년 기준 공통 요건은 대한민국 국적, 국내 초·중·고 재학생(초5~고3), 만 24세 이하다. 꿈장학금은 기초·차상위·한부모가족 지원대상자, 다문화장학금은 기초·차상위·한부모가족 지원대상자이면서 다문화가족에 해당하고 학교장 추천을 받은 학생이다. 직전학년 교과성적은 초5~중1 미적용, 중2~고1 C등급 이상, 고2 C등급 이상 또는 4등급 이내, 고3 C등급 이상 또는 7등급 이내다. 직전학년 출결은 초5~중1 미인정 결석 5일 미만, 중2~고3 10일 미만이다. 직전학년 봉사는 초5~중1 미적용, 중2~고3 5시간 이상이다. 자세한 사항은 한국장학재단 홈페이지에서 확인한다.
- 지원내용: 매월 15~45만원의 장학금을 학교급과 유형에 따라 차등 지급한다.
- 유의사항·예외: 상세정보에 별도 제외 조건이 없다.
- 신청방법: 학교가 추천한 학생을 해당 학교의 담당 교사가 한국장학재단 학자금지원시스템에 온라인으로 접수한다. 접수부터 사후관리까지 한국장학재단이 맡는다.
- 준비서류: 상세정보에 구체 목록이 없어 재학 학교 확인이 필요하다.
- 문의: 한국장학재단 상담센터 1599-2290.
