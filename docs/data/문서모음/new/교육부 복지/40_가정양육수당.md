# 가정양육수당 지원사업

- 분야: 보육 / 가정양육수당 / 중앙부처(교육부 영유아재정과)
- 서비스 ID: WLF00003253
- 지원대상: 어린이집·유치원(특수학교 포함)·종일제 아이돌봄서비스 등을 이용하지 않고 가정에서 양육되는 초등학교 미취학 24개월 이상~86개월 미만 아동. 0~23개월 아동은 부모급여를 지원한다. 초등학교 취학년도 2월까지(최대 86개월 미만) 지원하며 소득 수준과 관계없이 지원한다.
- 선정조건: 양육수당과 보육료 등 서비스를 바꾸려면 반드시 변경신청절차를 완료해야 한다. 보육료·유아학비에서 양육수당으로 바꿀 때는 15일 이전 신청 시 신청 월부터, 16일 이후 신청 시 신청 익월부터 지원한다. 종일제 아이돌봄에서 양육수당으로 바꿀 때는 신청 익월부터 지원한다.
- 지원내용: 취학 전 24개월 이상 86개월 미만 아동에게 월 10만원을 지원한다. 장애아동(10~20만원)과 농어촌아동(10~15.6만원)은 연령별로 차등 지원한다.
- 유의사항·예외: 어린이집·유치원(특수학교 포함)·종일제 아이돌봄서비스 등을 이용하면 대상이 아니다. 서비스 변경 시 지원 기준이 다를 수 있으므로 변경신청 기준을 미리 확인한다.
- 신청방법: 읍면동 행정복지센터를 방문하거나 복지로에서 온라인으로 신청한다. 복지로 온라인 신청은 영유아의 부모만 할 수 있으므로 불가능하면 방문 신청한다. 읍면동이 접수하고, 조사·결정·이의신청·지원·사후관리는 시군구가 맡는다.
- 온라인 경로: 복지로 로그인 → 서비스 신청 → 복지서비스 신청 → 복지급여 신청 → 영유아 → 양육수당(가정양육).
- 준비서류: 상세정보에 구체 목록이 없어 접수기관 확인이 필요하다. 참고자료로 2026년도 보육사업안내가 게시되어 있다.
