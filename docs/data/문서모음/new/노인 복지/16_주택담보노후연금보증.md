- 서비스 ID: WLF00001108
- 지원대상: 일반 주택연금 가입요건은 다음과 같습니다. 만 55세 이상(부부인 경우 연장자 기준) 합산가격 공시가격 12억원 이하 주택 소유자. 부부기준 보유주택 합산가격. 공시가격 12억원 이하시 : 거주하는 1주택으로 주택연금 가입. 공시가격 12억원 초과시 : 2주택을 보유한 경우에 한하여 3년 이내에 담보주택외의 주택을 처분하는 조건으로 가입. 주택법상 주택 및 노인복지주택, 주택면적 1/2이상인 복합용도주택, 주거목적 오피스텔을 대상으로 합니다.

- 신청방법: 주택금융공사에 문의(1688-8114)후 신청해주시기 바랍니다.
