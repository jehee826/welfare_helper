# 농업인 연금보험료 지원

- 분야: 생활지원 / 현금지급 / 중앙부처(농림축산식품부 농촌사회서비스과)
- 서비스 ID: WLF00001097
- 지원대상: 국민연금 지역가입자 및 지역 임의계속 가입자 중 농업인에게 지원합니다.
- 선정조건: 국민연금 지역가입자(당연/특례) 중 농업인은 다음과 같습니다. 지역가입자에서 임의계속가입자로 된 농업인. 「국민연금법」시행령 제57조 제1항에서 정하고 있는 농업인. 「농업·농촌 및 식품산업 기본법」제3조제2호 규정에 해당하는 자.
- 지원내용: 본인이 부담할 연금보험료의 50%를 초과하지 않는 범위 내에서 월 최대 50,350원을 지원합니다. 기준소득월액 106만원 이하의 경우 월 연금보험료의 50%. 기준소득월액 106만원 초과의 경우 50,350원(정액)
- 유의사항·예외: 단, 농업경영체 등록자는 별도 증빙서류 제출 없이 국민연금공단에 바로 신청 가능.
- 신청방법: 국민연금 농업인 확인서 작성 후 이·통장 확인(1차) 및 읍면동장 확인(2차) 후 국민연금공단에 제출합니다. 단, 농업경영체 등록자는 별도 증빙서류 제출 없이 국민연금공단에 바로 신청 가능.
- 준비서류: 신청서(국민연금공단), 농업인 확인서(농업경영체 등록확인서 등). 상세페이지 서식·자료: 2026년 농업인 건강·연금보험료지원 사업시행지침.
- 문의: 국민연금공단 1355.
