- 서비스 ID: WLF00001176
- 지원대상: 암 종류별 대상자 기준(표준 검진 연령 및 성별) 및 검진주기는 다음과 같습니다. (위암) 40세 이상의 남성과 여성 / 2년. (간암) 40세 이상의 해당연도 전 2년간 간암발생고위험군 해당자 / 6개월. (대장암) 50세 이상의 남성과 여성 / 1년. (유방암) 40세 이상의 여성 / 2년. (자궁경부암) 20세 이상의 여성 / 2년.
