# 의료급여(의료급여대지급금지원)

- 분야: 신체건강·정신건강 / 현금대여(융자) / 중앙부처(보건복지부 기초의료보장과)
- 서비스 ID: WLF00003190
- 지원대상: 보장기관(시군구 또는 읍면동)에 대지급금을 신청한 수급자 중 대불조건에 해당되는 수급자를 대상으로 지원합니다. 비급여 항목은 지원대상 아님.
- 선정조건: 상세정보에 지원대상 외의 별도 선정기준이 없다.
- 지원내용: 의료급여 2종 수급권자가 의료급여기관에 입원하여 발생한 급여비용 중 본인부담금이 20만원을 초과한 경우, 20만원을 초과한 금액중 수급권자 본인 또는 부양의무자의 신청에 의해 보장 기관이 승인한 금액.
- 유의사항·예외: 상세정보에 별도 제외·주의사항이 기재되어 있지 않다. 세부 기준은 신청기관에 확인한다.
- 신청방법: 수급권자 본인 또는 그 부양의무자가 대지급 신청서 작성하여 의료급여기관의 확인을 받아 거주지 시장, 군수, 구청장에게 제출합니다.
- 준비서류: 대지급금 신청서(시·군·구), 진료비 내역. 상세페이지 서식·자료: 2026년도 의료급여사업 안내.
- 문의: 보건복지부 상담센터 129.
