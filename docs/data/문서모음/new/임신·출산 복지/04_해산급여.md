# 해산급여

- 분야: 생활지원·임신·출산 / 현금지급 / 중앙부처(보건복지부 기초생활보장과)
- 서비스 ID: WLF00001135
- 지원대상: 생계, 의료, 주거급여 수급자가 출산한 경우(출산예정 포함) 해산급여를 지급합니다.
- 선정조건: 상세정보에 지원대상 외의 별도 선정기준이 없다.
- 지원내용: 수급자가 출산(출산예정 포함)한 경우 1인당 70만원을 지급합니다. 추가 출생영아 1인당 70만원 추가지급(쌍둥이 출산 시 140만원 지급)
- 유의사항·예외: 상세정보에 별도 제외·주의사항이 기재되어 있지 않다. 세부 기준은 신청기관에 확인한다.
- 신청방법: 복지대상자 해산급여 지원신청서를 시군구청장에게 제출합니다. 출생증명서는 출생신고로 대체 가능. 출산예정자는 출산예정일 4주 전부터 신청가능(의사소견서 또는 의사 진단서, 산모수첩, 인우증명서를 통해 확인) 사산의 경우 의사, 한의사 또는 조산사의 사실확인서를 첨부하여 신청합니다. 거주지 관할 지역이 아니더라도 전국 어디서나 신청이 가능합니다. 복지로( www.bokjiro.go.kr ) 서비스신청을 통한 온라인신청이 가능합니다. 복지로 온라인신청 경로 : 복지로 로그인 > 서비스 신청 > 복지서비스 신청 > 복지급여 신청 > 저소득층 > 해산/장제.
- 준비서류: 신청서(주민센터), 출생 증빙(출생증명서). 상세페이지 서식·자료: 2026년 국민기초생활보장 사업안내.
