# 국민연금 출산크레딧

- 분야: 생활지원 / 현금지급 / 중앙부처(보건복지부 연금급여팀)
- 서비스 ID: WLF00004647
- 지원대상: 자녀(출산 또는 입양)가 있는 국민연금 가입자 또는 가입자였던자가 노령연금 수급권을 취득한 자를 대상으로 합니다.
- 선정조건: 상세정보에 지원대상 외의 별도 선정기준이 없다.
- 지원내용: 2008.1.1 이후 자녀를 출산(입양포함)한 국민연금 가입자에게 자녀수에 따라 가입기간을 추가로 인정합니다. 자녀가 2명인 경우 : 자녀 1명마다 12개월을 더한 개월 수. 자녀가 3명 이상인 경우 : 첫째 및 둘째 자녀에 인정되는 24개월에 셋째 자녀 이상 1명마다 18개월씩 추가하여 더한 개월 수를 가입기간으로 추가 산입. 단, '26년1.1 시행 기준으로 '08년~'25년까지는 둘째부터 12개월, 셋째부터 자녀당 18개월 상한 50개월 적용.
- 유의사항·예외: CSV 비고: 확대 기준 확인 필요. 단, '26년1.1 시행 기준으로 '08년~'25년까지는 둘째부터 12개월, 셋째부터 자녀당 18개월 상한 50개월 적용.
- 신청방법: 노령연금 수급권을 취득한 때나, 가입기간을 추가로 인정받아 노령연금 수급권을 취득할 수 있는 경우 신청하면 출산크레딧 추가 가입기간을 포함해서 산정된 노령연금이 지급됩니다. 국민연금공단을 직접 방문하여 신청하거나, 국민연금공단 홈페이지( www.nps.or.kr )을 통해 온라인 신청이 가능합니니다.
- 준비서류: 노령연금 청구 시 함께 신청, 가족관계증명서.
