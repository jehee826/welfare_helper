# 고엽제특별지원

- 분야: 소득·생활지원 / 보훈 위문품 / 중앙부처
- 서비스 ID: WLF00003261
- 지원대상: 생계가 곤란한 고엽제후유증환자 중 「장애인복지법」상 장애인 자녀가 있는 가정, 그리고 고엽제후유증 2세환자 중 등급기준 미달자.
- 선정조건: 고엽제후유증환자 여부, 자녀의 장애 여부, 생활수준 조사 결과 등을 종합 검토해 선정한다.
- 지원내용: 약 20만 원 상당의 위문품을 지원한다. 단가는 해당 연도 예산범위 내에서 조정된다.
- 유의사항·예외: 현금이 아닌 현물(위문품) 지원이다.
- 신청방법: 직접 조회한 상세페이지에 신청방법 본문이 비어 있어 보훈상담센터 또는 관할 보훈(지)청 확인이 필요하다.
- 준비서류: 상세페이지에 구체 목록이 없어 보훈상담센터 확인이 필요하다.
