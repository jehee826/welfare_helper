# 장애인보조기기 교부

- 분야: 보조기기 / 저소득 장애인 보조기기 현물지원 / 중앙부처
- 서비스 ID: WLF00003211
- 지원대상: 지원품목별 장애유형(지체, 뇌병변, 시각, 청각, 심장, 호흡, 지적, 자폐성, 언어)에 해당하는 등록장애인 중 국민기초생활보장 수급자 및 차상위계층.
- 선정조건: 차상위계층은 차상위계층 확인, 차상위자활, 차상위본인부담, 차상위장애인(차상위 장애수당, 차상위 장애인연금 부가급여 등), 한부모가족지원, 차상위 자산형성 지원 등을 포함한다. 국민연금공단의 최소적격성 검사에서 '적격' 판정을 받아야 한다.
- 지원내용: 교부품목별 장애유형과 지원기준에 맞는 보조기기를 현물로 지원한다.
- 유의사항·예외: 품목별로 해당 장애유형이 정해져 있어 장애유형에 맞지 않는 품목은 지원되지 않는다. 구체 품목과 기준은 사업안내에 따른다.
- 신청방법: 읍면동 주민센터 방문 신청 → 시군구 확인 후 국민연금공단 서비스지원 종합조사(최소적격성 검사) → 지역보조기기센터 상담·평가 → 시군구에서 보조기기 제공.
- 준비서류: 직접 조회한 상세페이지에 구체 목록이 없어 읍면동 주민센터 확인이 필요하다.
- 문의: 보건복지상담센터 129, 중앙보조기기센터 1670-5529.
