# 의료급여 장애인보조기기 지원

- 분야: 보조기기 / 의료급여 수급 장애인 / 중앙부처
- 서비스 ID: WLF00000067
- 지원대상: 의료급여 수급권자 중 「장애인복지법」에 따라 등록한 장애인.
- 선정조건: 위 지원대상 요건에 해당하면 된다.
- 지원내용: 의료급여 대상 장애인보조기기의 유형, 기준액, 내구연한에 따라 구입비용을 지원한다(「국민건강보험법」 시행규칙 별표7 제2호). 유형별 기준액, 고시금액, 실구입금액 중 가장 낮은 금액을 지원한다.
- 유의사항·예외: 기금 부담액 외의 금액은 수급권자가 전액 부담한다. 건전지 등 소모품 구입비와 수리비는 지원하지 않으며, 전동휠체어·전동스쿠터 장착용 전지만 예외로 지원한다.
- 신청방법: 주소지 읍면동 주민센터에 방문해 신청한다.
- 준비서류: 직접 조회한 상세페이지에 구체 목록이 없어 읍면동 주민센터 확인이 필요하다.
- 문의: 보건복지상담센터 129.
