# 청소년 발달장애인 방과후활동서비스

- 분야: 돌봄·활동지원 / 발달장애 청소년 방과후 돌봄 / 중앙부처
- 서비스 ID: WLF00001178
- 지원대상: 만 6세 이상~만 18세 미만 「장애인복지법」상 등록된 지적장애인 및 자폐성장애인.

- 유의사항·예외: 만 18세 이상 재학생은 방과후활동서비스와 주간활동서비스를 중복 이용할 수 없다.

- 준비서류: 상세페이지 서식 기준 사회보장급여(사회서비스이용권) 신청(변경)서. 만 18세 이상 재학생은 발급 1개월 이내 재학증명서.
