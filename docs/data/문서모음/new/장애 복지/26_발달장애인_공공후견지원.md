# 발달장애인 공공후견지원 사업

- 분야: 돌봄·활동지원 / 의사결정 지원·후견 / 중앙부처
- 서비스 ID: WLF00000065
- 지원대상: 19세 이상 성인 발달장애인(「장애인복지법」상 지적·자폐성 장애인, 부장애로 가진 경우 포함) 중 의사결정 지원이 필요한 사람.
- 선정조건: 위 등록기준과 욕구기준을 충족하면 된다.
- 지원내용: 공공후견 심판청구비용을 실비로 1인당 최대 50만 원 지원한다(초과 시 중앙·지역발달장애인지원센터 판단으로 지급 가능). 공공후견인 활동비용은 상세페이지에 '월 20만 원, 월 최대 60만 원'으로 표기되어 있으며, 후견법인이 공공후견인이 되는 경우 활동비는 같되 상한 제한이 없다.
- 유의사항·예외: 후견심판청구, 후견인 활동 지원·감독 주체는 피후견인 주민등록상 주소지 기준 시·군·구다.
- 신청방법: 본인, 가족, 지역발달장애인지원센터, 사회복지시설 종사자, 읍면동 주민센터 등이 대상자 주민등록상 주소지 관할 읍·면·동 또는 시·군·구에 연중 방문 신청한다.
- 준비서류: 공공후견지원사업 이용 신청서, 개인정보제공동의서, 후견심판청구 동의서(사건본인용·이해관계인용), 후견심판청구에 대한 본인의 의향 확인서.
- 문의: 보건복지상담센터 129.
