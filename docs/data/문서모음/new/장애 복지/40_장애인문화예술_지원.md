# 장애인문화·예술 지원

- 분야: 문화·체육 / 장애예술인 공모 지원 / 중앙부처
- 서비스 ID: WLF00001117
- 지원대상: 함께누리 지원(공모) 사업에 신청한 장애예술인 및 단체. 주관은 문화체육관광부와 한국장애인문화예술원이다.
- 선정조건: 공모 프로그램 유형별 적합성을 검토해 선정한다. 세부 기준은 한국장애인문화예술원 홈페이지(www.i-eum.or.kr) 공고를 따른다.
- 지원내용: 장애예술 창작역량 강화, 장애인 공연예술단, 장애인 문화향유활동(축제·경연·교류), 지역대상 문화활성화, 문화소외계층 지역대상 문화예술 활성화를 지원한다.
- 유의사항·예외: 공모 신청과 대상자 선정은 1~2월, 사업기간은 2~12월이다. 연중 상시 신청 사업이 아니다.
- 신청방법: 한국장애인문화예술원 홈페이지 공고를 확인해 온라인으로 신청한다.
- 준비서류: 공고문의 지원신청서 양식. 상세페이지에 게시된 신청서 서식은 2021년 양식이므로 해당 연도 공고 확인이 필요하다.
- 문의: 한국장애인문화예술원 02-760-9700.
