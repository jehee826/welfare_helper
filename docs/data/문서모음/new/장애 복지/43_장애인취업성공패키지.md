# 장애인취업성공패키지

- 분야: 일자리 / 통합 취업지원 / 중앙부처
- 서비스 ID: WLF00004655
- 지원대상: 취업을 희망하는 만 18세 이상~69세 이하 장애인(중위소득 60% 이하 저소득층 포함). 69세를 넘어도 상담·평가로 취업의욕과 역량이 높으면 참여 여부를 판단한다.
- 선정조건: 「장애인복지법 시행령」 제2조의 장애인 기준 또는 국가유공자 상이등급 기준에 해당해야 하며, 참여일 기준으로 장애등록사항과 상이등급 유지 여부를 확인한다. 저소득층 참여자는 중위소득 60% 이하 여부를 확인해 별도 서비스를 제공한다.
- 지원내용: 상담·취업계획 수립 → 직업능력 향상 → 집중 취업알선의 통합 취업지원 프로그램을 제공하고, 참여 단계와 유형에 따라 참여수당을 지급한다.
- 유의사항·예외: 참여수당 금액은 상세페이지에 명시되어 있지 않아 한국장애인고용공단 확인이 필요하다.
- 신청방법: 가까운 한국장애인고용공단에 문의한 뒤 참여한다.
- 준비서류: 직접 조회한 상세페이지에 구체 목록이 없어 한국장애인고용공단 확인이 필요하다.
- 문의: 한국장애인고용공단 1588-1519.
