# 직업능력개발운영(훈련수당)

- 분야: 일자리 / 장애인 직업훈련 / 중앙부처
- 서비스 ID: WLF00004651
- 지원대상: 직업능력개발훈련을 희망하거나 필요로 하는 15세 이상 장애인. 한국장애인고용공단 직업능력개발원의 정규훈련(융복합·특화훈련) 훈련생, 1개월 이상이며 계획 훈련시간 120시간 이상인 맞춤훈련 과정 훈련생, 공단이 지원하는 공공(폴리텍)·민간훈련기관 훈련생.
- 선정조건: 위 지원대상 요건에 해당하면 된다.
- 지원내용: 훈련참여수당 월 200,000원(취업성공패키지 연계 대상은 월 284,000원), 기숙사에 살지 않는 훈련생 교통비 월 50,000원, 식비 월 66,000원(통학생 중 식이조절 등으로 개별 도시락을 지참하는 훈련생, 민간훈련기관은 1일 5시간 이상·월평균 100시간 이상 훈련생).
- 유의사항·예외: 실업급여 수급자, 다른 법령에 따라 훈련수당·훈련장려금을 받는 사람, 월 출석률 80% 미만 훈련생에게는 훈련수당을 지급하지 않는다.
- 신청방법: 공단 직업능력개발원·지역본부·지사 또는 거주지 인근 공단지정 민간위탁훈련기관(www.kead.or.kr 참조)의 훈련과정에 방문해 참여한다.
- 준비서류: 직접 조회한 상세페이지에 구체 목록이 없어 한국장애인고용공단 확인이 필요하다.
- 문의: 한국장애인고용공단 1588-1519, 고용노동부 종합상담센터 1544-1350.
