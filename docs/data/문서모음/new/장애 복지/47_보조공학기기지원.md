# 보조공학기기지원

- 분야: 일자리 / 작업용 보조공학기기 / 중앙부처
- 서비스 ID: WLF00003231
- 지원대상: 장애인 근로자(공무원 포함), 장애인을 고용하거나 고용하려는 사업주, 근로자 4인 이하 규모의 장애인 사업주. 고용지원 필요도 결정에 따라 지원이 필요하다고 판단된 장애인도 포함한다.
- 선정조건: 신청 대상자별로 보조공학기기 신청서를 작성하며, 사업주 신청 시 기기별로 사용할 장애인 근로자를 지정해야 한다. 상담·평가로 타당성을 검토해 접수일로부터 30일 이내에 지원 여부를 결정한다.
- 지원내용: 직업생활에 필요한 작업보조 공학기기·장비의 구입 및 대여 비용을 장애인 1인당 1,500만 원(중증 2,000만 원) 한도로 지원한다. 공단이 선정한 보조공학기기 제품 내에서 지원한다.
- 본인부담: 지원결정 후 기기금액의 최대 10%를 본인부담금으로 납부한다. 기초생활수급자와 차상위계층은 면제다.
- 유의사항·예외: 중복 품목은 지원하지 않는다. 기기 구입일로부터 2년간 고용(근무)을 유지해야 하며, 지급보증보험증권 제출이 필수다.
- 신청방법: 사업장 소재지 관할 한국장애인고용공단 지역본부·지사에 방문, 우편, 이메일, 팩스, 인터넷으로 신청한다.
- 준비서류: 보조공학기기 신청서, 지원결정 후 지급보증보험증권.
- 문의: 한국장애인고용공단 1588-1519.
