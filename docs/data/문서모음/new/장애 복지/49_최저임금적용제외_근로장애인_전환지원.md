# 최저임금적용제외 근로장애인 전환지원

- 분야: 일자리 / 직업재활시설 근로장애인 전환 / 중앙부처
- 서비스 ID: WLF00001187
- 지원대상: 「장애인고용촉진 및 직업재활법」상 장애인으로서 장애인직업재활시설에 소속된 최저임금 적용제외 근로장애인.
- 선정조건: 위 지원대상 요건에 해당하면 된다. 상세 선정요건은 한국장애인고용공단 확인이 필요하다.
- 지원내용: 전환준비 → 전환지원 → 고용안정 3단계로 역량강화와 취업연계를 지원한다. 장애인에게는 전환준비단계 고용전환촉진수당(월 30만 원 한도)과 전환 성공 시 전환성공수당 3개월간 최대 100만 원(1개월 20만 원, 2개월 30만 원, 3개월 50만 원)을 지급한다. 참여자를 채용한 사업주에게는 월 90만 원 한도로 최대 3년간 지원금을, 시설에는 전환성공지원금 3개월간 최대 60만 원을 지급한다.
- 유의사항·예외: 최저임금 이상 일자리로의 전환이 목적인 사업으로, 수당은 단계별 요건 충족 시 지급된다.
- 신청방법: 가까운 한국장애인고용공단 소속기관에 문의해 이메일·방문·우편·팩스로 신청한다.
- 준비서류: 참여신청서. 그 밖의 서류는 한국장애인고용공단 확인이 필요하다.
- 문의: 한국장애인고용공단 1588-1519.
