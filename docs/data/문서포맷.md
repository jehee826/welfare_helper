# 복지서비스 문서 포맷

작성: 2026-11-05. 최신 업데이트: 2026-11-05 15:43 KST

Docling은 문서 구조를 분석하고 임베딩은 관련 내용을 찾는다. 원문만 읽어도 의미가 분명하면 그대로 사용한다. 아래는 기존 노인복지 자료 10종에서 사용한 편집 기준이며, 제목·항목 순서·화살표·검색어 목록은 선택 사항이다.

- **제도의 경계를 표시한다.** 여러 제도가 한 원본에 섞여 있으면 제도별 제목으로 구분하고, 관리자에서 각각 다른 제도로 게시할 때는 파일도 나눈다. 같은 제도의 여러 지원 유형은 소제목으로 구분해도 된다.
- **조건은 그 조건이 적용되는 혜택 곁에 둔다.** 대상·지역·기준연도, 금액·단위·상한, 제외·예외 중 원문에 있는 내용을 살린다. 표를 문장으로 바꿀 때도 행·열의 관계를 보존한다. 예를 들어 일반공급과 우선공급의 소득 기준을 한 목록으로 합치면 어느 기준이 누구에게 적용되는지 알 수 없다.
- **신청방법은 순서와 선택지를 구분한다.** 원문에서 확인한 메뉴 순서는 화살표나 번호로 표시한다. 방문·온라인처럼 둘 중 하나를 고르는 경로는 각각 적는다. 신청자가 할 일과 접수기관의 후속 처리는 주어를 밝혀 구분한다. 나열된 단어만으로 순서를 판별할 수 없다면 공식 원문을 대조하고, 확인한 범위까지만 적는다.
- **출처와 문의처를 남긴다.** 공식 원문 링크와 확인 가능한 자료 기준일을 적는다. 담당 기관과 번호는 짝지어 쓰고 일반 상담번호는 구분한다. 필수서류·금액·온라인 경로 등이 명시되지 않았으면 추측해 채우지 않는다.

**기초연금 자료의 작성 예시**

방문 신청은 읍면동 주민센터·행정복지센터 또는 전국 국민연금공단 지사에서 한다. 온라인 신청 경로는 `복지로 로그인 → 서비스 신청 → 복지서비스 신청 → 복지급여 신청 → 노년 → 기초연금`이다. 방문과 온라인은 대안이고, 화살표는 온라인에서 눌러야 할 메뉴 순서만 뜻한다.
