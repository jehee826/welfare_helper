# 복지서비스 자료 수집 방법

작성: 2026-11-05. 최신 업데이트: 2026-11-05 15:43 KST

1. 복지로나 담당 기관에서 서비스의 **공식 상세 페이지**를 연다. 검색 결과나 목록은 상세 페이지를 찾는 용도로 사용한다.
2. 서비스명, 출처 URL, 담당 기관과 확인한 날짜를 기록한다. 기준연도·원문 수정일·적용 지역은 원문에서 확인되는 값만 옮긴다. 수집한 날짜와 원문 수정일은 따로 적는다.
3. 대상·지원 내용·예외·신청 방법·문의처를 해당 제도와 함께 옮긴다. 메뉴나 표를 평문으로 읽었을 때 뜻이 달라지는 부분만 [문서 포맷](문서포맷.md)에 맞춰 정리한다. 신청 양식 대신 공개된 서비스 안내를 수집한다.
4. [문서 모음](문서모음/)에서 서비스 ID나 공식 URL을 대조한다. 같은 서비스의 새 자료라면 기존 파일을 갱신하고, 다른 서비스라면 서비스명을 알아볼 수 있는 이름으로 추가한다. 숫자·단위·신청 순서·연락처를 공식 원문과 한 번 대조한다.

관리자 업로드에는 문서 모음 안의 서비스 자료만 선택한다. 가이드 두 개는 자료 작성자가 읽는 문서다.
