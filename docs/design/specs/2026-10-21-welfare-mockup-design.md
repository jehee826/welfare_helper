# 웹 화면과 시연 범위

최초 목업 설계의 파일명은 유지하되 본문은2026-11-02 현재 구현에 맞춰 갱신했다. 목업 API를 현재 기본 데이터 경로로 안내하지 않는다.

## 현재 화면

React/Vite 웹은 문서 기반 상담, 원문 근거 표시, 사용자 조건·지난 상담의 브라우저 저장, 관리자 공통 비밀번호 로그인과 문서/제도 관리를 제공한다. 원문 업로드 후 자동 분석·청크·임베딩·게시 진행 상태를 보여준다.

운영 HTTP API는 목업 fallback을 사용하지 않는다. 관리자 이용 통계는 아직 서버와 미연동이며 수치·상담원 연결·해결률을 운영 기능으로 표시하지 않는다. 테스트에서 직접 주입한 목업은 테스트 자료임을 구분하고, 화면은 로딩·미연동·오류·빈 결과와 해제 후 늦은 응답을 처리한다. 새 통계 DB/API나 상담원 연결 기능을 구현한 것은 아니다.

복지로 위 화면 안내는 별도의 Chrome 확장 패널에서 수행한다. 사용자 질문에 설명과0~3개 실제 요소 강조를 제공하고 클릭은 사용자가 직접 한다. Electron/Desktop은 이전 구현 참고이며 현재 확장 시연의 설치 전제가 아니다.

디자인은 기존 화면 구성을 유지하며 진행·오류·취소·완료 상태를 구분한다. 기능 설명과 실제 검증 결과를 섞지 않는다. 실행은 [프로젝트 README](../../../README.md), [확장 README](../../../Extension/README.md), 남은 차이는 [구현 현황](../implementation-gap-analysis.md)을 따른다.
