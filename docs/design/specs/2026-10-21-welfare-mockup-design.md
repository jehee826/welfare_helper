# 웹 화면과 시연 범위

최초 목업 설계의 파일명은 유지하되 본문은2026-11-02 현재 구현에 맞춰 갱신했다. 목업 API를 현재 기본 데이터 경로로 안내하지 않는다.

## 현재 화면

React/Vite 웹은 관리자 공통 비밀번호 로그인과 문서·제도 관리 전용이다. `/`·`/admin`·알 수 없는 경로는 `/admin/documents`로 replace 이동한다. 문서·제도 경로는 상위 레이아웃의 공통 AdminGate를 통과하며 권한 확인 전에는 관리 데이터를 불러오지 않는다. 원문 업로드 후 자동 분석·청크·임베딩·게시 진행 상태와 문서별 검색·질의를 제공한다.

공개 웹 상담·조건·지난 상담 화면과 미연동 통계 탭은 제거했다. 기존 브라우저 저장값은 삭제하거나 이전하지 않는다. 운영 HTTP API는 목업 fallback을 사용하지 않으며 테스트에서 직접 주입한 목업과 구분한다. 기존 관리자 세션 URL·서버 인증과 확장이 사용하는 공개 `/api/v1/chat`은 유지한다.

일반 사용자 상담과 조건·이전 상담 저장은 복지로의 Chrome 확장 패널에서 제공한다. 공개 화면 안내는 설명과0~3개 실제 요소 강조를 제공하고 클릭은 사용자가 직접 한다. 원격 문서 패키지의 화면 안내는 별도 구현 범위다. Electron/Desktop은 이전 구현 참고이며 현재 확장 시연의 설치 전제가 아니다.

디자인은 기존 화면 구성을 유지하며 진행·오류·취소·완료 상태를 구분한다. 기능 설명과 실제 검증 결과를 섞지 않는다. 실행은 [프로젝트 README](../../../README.md), [확장 README](../../../Extension/README.md), 남은 차이는 [구현 현황](../implementation-gap-analysis.md)을 따른다.
