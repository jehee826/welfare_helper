## 남은 검증과 기록 위치

- 실제 Chrome 상담·저장/F5·요약·DOM·음성, Docling 작업 종료/메모리 회수, 별도 연락처 CSV, W14 운영 적용, W15 영속 인증 전환, 최종 배포/PR 판정이 남았다. 자세한 완료 기준은 기존 실행 계획5절을 따른다.
- [개발일지](devlog.md)는 실제 경과를 누적하고 이 문서는 현재 상태로 갱신한다. [기존 노트북 인계](laptop_handoff.md)는 당시 상세 스냅샷이며 이후 현재 상태는 이 문서에서 확인한다.
- 옛 `docs/log/development.md`·`handoff.md`와 빈 폴더는 사용자 요청으로 로컬에서 삭제했다. EC2에는 해당 폴더가 없었다. 실제 `.env`·키·비밀번호·개인 질문·상담 원문은 공유 기록에 넣지 않는다.
