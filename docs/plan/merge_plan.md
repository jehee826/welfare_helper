## 4. 최종 사용자 확인과 통합

- 실제 확장 한 묶음은 최신 피드백이 반영된 기존 설치에서 수행한다: 상담/후속·주제전환, 내 정보 ON/OFF·대상 정정, 대화/요약 F5 복원·두 탭, DOM 테두리, 패널/F12·모달·불투명도·키보드/200%, 낭독·마이크·요청 중지. 삭제/재설치·전체 상담 삭제를 준비 절차로 쓰지 않는다.
- 상태: **최종 버전 사용자 확인 대기**. 과거 자동 검사와 실제 요약/DOM HTTP 결과로 설치 Chrome 통과를 대신하지 않는다. [기존 준비 완료 범위](devlog.md#log-20261109-1706-6759ba) / [최신 변경](devlog.md#log-20261110-1039-acc25e)
- 최종 main 통합은 **미완료**다. 변경한 경로의 필요한 검사와 서버/확장/관리자 버전을 맞추고, 사용자가 PR 생성·검토·병합한 뒤 Vercel production 및 변경 경로를 확인한다. main 직접 반영·PR 생성 대행은 하지 않는다.

## 5. 보류·현재 범위 제외

- RAG 정확도/B안: 자료 밖 지급일·질문 항목 누락·조건 논리 오류가 실제 관측돼 보류했다. B안11파일과 첫 결과를 보존하며 운영에 자동 채택하지 않는다. [실제 실패 근거](devlog.md#log-20261109-1307-d43ea6)
- CSV/W03·W14: 사용자가 지정할 별도 파일 경로를 기다리고 수집은 OFF 유지한다. 보유 공공CSV·문서 연락처를 그 자료로 간주하지 않는다. [대기 근거](devlog.md#log-20261109-1614-4b459e)
- 실제 관리자 정상 UI·production 비밀번호 회전·실제 EC2 재부팅·변환 도중 취소/GPU 메모리는 미실측이다. 현재 시연을 위해 가정한 장애/복구·부하 시험을 새 필수로 늘리지 않는다. [완료와 미실측 구분](devlog.md#log-20261109-1706-6759ba)
- 사용자 웹의 PWA·네이티브·모바일 전용 기능·영속 기록·계정 동기화·웹스토어/타 브라우저·자동 자료 수집은 현재 최소 범위에서 제외한다.
